# Stasis Mod

The Stasis Mod is a Minecraft mod for Fabric 1.21.1 with loader version 0.15.11. It allows players to place an Enderman in a Stasis block using a lead, causing the Enderman to inflate its belly and stay in the Stasis block. This mod is compatible with the Create mod and requires a Stasis block, a lead, and an Enderman to function.

## Install

1. Install Fabric 1.21.1 with loader version 0.15.11.
2. Download the Stasis Mod jar file.
3. Place the jar file in the mods folder.

## Use

1. Craft a Stasis block using the recipe.
2. Place the Stasis block in the world.
3. Right-click the Stasis block with a lead to place an Enderman inside.
4. The Enderman will inflate its belly and stay in the Stasis block.
